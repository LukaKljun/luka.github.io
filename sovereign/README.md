# SOVEREIGN — Command your day

A mobile-first, local-first private command centre: daily briefings, timeline, missions, contacts, focus sessions, intelligence and evening debriefs. Built as a static progressive web app with no backend.

Live site: https://lukakljun.github.io/luka.github.io/sovereign/

SOVEREIGN is hosted in its own folder within the existing GitHub Pages repository. Open **index.html** in a browser or serve this directory over HTTPS. The website works on iPhone; use Safari's Share > Add to Home Screen to install it.

Data lives in localStorage on the current device and is not encrypted or synchronized; export JSON backups in Settings. Discreet mode masks labels on screen only. Q is a built-in rule-based assistant, not a cloud AI model. iCalendar .ics import/export does not provide live Google Calendar sync.
